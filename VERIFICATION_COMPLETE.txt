HOW IT WORKS - EXAMPLE

Alice makes deposits:
  1. Deposit 1000 USDC → ID=0 (counter: 0 → 1)
  2. Deposit 500 USDC → ID=1 (counter: 1 → 2)
  3. Withdraw ID=0
  4. Deposit 800 USDC → ID=2 (counter: 2 → 3) ← continues from 2, not 0
  5. Cancel ID=1
  6. Deposit 200 USDC → ID=3 (counter: 3 → 4) ← continues from 3, not 0

Storage:
  DepositCounter(alice) = 4
  Deposit(alice, 2) = 800 USDC
  Deposit(alice, 3) = 200 USDC
  ActiveDepositIds(alice) = [2, 3]

Result: IDs never reused or reset ✓
